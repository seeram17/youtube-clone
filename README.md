# YouTube Clone 

A responsive YouTube homepage clone built using **HTML and CSS**.  
This project replicates the layout and UI of YouTube’s home page, focusing on structure, styling, and responsiveness.

---

##  Live Demo
https://seeram17.github.io/youtube-clone/

---

## Features
- YouTube-style header with search and icons
- Sidebar navigation menu
- Video grid layout
- Channel avatars and video metadata
- Hover effects and tooltips
- Responsive layout using CSS Grid & Flexbox

---

##  Built With
- HTML5
- CSS3 (Flexbox & Grid)
- Google Fonts (Roboto)

---
